Le Piano House Project est le grand chapeau sous lequel se range tout ce que je construis ; ce site — selected projects — est l'un des projets qu'il abrite : une vitrine qui sert aussi de banc d'essai pour le reste.

Les présentations de chaque projet sont rédigées par un agent qui lit mes propres journaux de session — le même pipeline qui produit les textes « évolution » ailleurs sur le site a aussi produit cette page. C'est donc une version digérée du travail réel, y compris du travail de construction de ce site.
